# 附录

正文给出的每一条量级结论，都可以回到两类可核对的东西：仓库中可复算的计算工具，以及仓库中归档的原始来源。这个附录把两者整理成可直接查用的清单。A 汇总全书符号、缩写与物理量；B 说明仓库怎么用、数字怎么复算；C 按用途列出高分子 AI 的常用工具与数据资源，并标出每个来源的归档状态；D 按任务、样本量与实验预算给出表示、模型与闭环策略的选型；E 列出会改变数据与实验结论的几类事实；F 把全书反复出现的关键数字集中编号，供各章直接引用；G 至 J 分别是参考文献、数据集索引、软件工具索引与配套仓库资源；K 是主题索引。全书反复追问的五个问题——表示什么、数据够不够、用什么模型、怎么搜索、闭环到什么程度——在这里收束成一张张可查的表。

### B.2 如何运行复算

复算工具只用 Python 标准库，在仓库根目录执行一条命令即可重建全部结果：

```bash
python3 calculations/calc.py reproduce
```

该命令重新生成 `calculations/results/` 下的全部 `.json` 与 `.md`，正文引用的数字取自这些结果。校验与测试用另外三条命令：

```bash
python3 calculations/calc.py verify-results
python3 calculations/calc.py verify-sources
python3 -m unittest discover -s calculations/tests -v
```

`verify-results` 校验结果与输入哈希是否仍然一致，`verify-sources` 校验配置对来源锁文件的引用，测试包含单位校验、小规模暴力枚举交叉检验、碰撞闭式解、几何期望、学习曲线反解、FLOP 守恒与结果契约检查。每个专题都是一个纯函数 `calculate(...) -> dict`，输入是场景参数，输出遵循统一的七字段契约：`schema_version`、`calculation`、`model`、`scenario`、`sources`、`summary`、`assumptions`。任意专题都支持 `--format {json,md}` 与 `--output PATH`，也可以改一个参数重算：把链长从 100 改成 50，无规序列空间从 $10^{100}$ 降到 $10^{50}$；把库规模从 $10^{6}$ 提到 $10^{7}$，位指纹存储从 256 MB 涨到 2.6 GB。完整的子命令与专题说明见 [`calculations/README.md`](../calculations/README.md)。[^calc]

### B.4 已知限制与已知问题

把边界写进附录，是为了让读者在复现之前就知道哪些结论本书没有、也不声称有。以下三项是本书明确记录的限制。

**没有运行任何墙钟基准。** 正文以秒、微秒或 GPU·秒给出的计算代价，全部是理想算术下界（ideal arithmetic lower bound）：由声明模型算出 FLOPs，再除以声明峰值吞吐，未计入内存带宽、kernel launch、batch size、通信、I/O 与软件实现质量。它们回答「需要多少次浮点运算」，不回答「在目标硬件上跑多快」；真实墙钟时间通常高于该下界。

**来源归档只保存能自动下载到的内容。** `references/files/` 只包含实际取得副本的来源。本附录 G 引用的 289 条来源中，15 条被出版社反爬拦截（HTTP 403）而未能下载，4 条为订阅来源、只保留落地页，另有少数条目正文过短。这些来源只用于领域定位，正文不引用其中无法核对的具体数字；完整状态见 [`references/NEEDED.md`](../references/NEEDED.md)。

**图内字体依赖随仓库提供的思源黑体。** 章节配图使用随仓库分发的 Source Han Sans CN。在未执行 `git lfs pull`、因而不含该字体的机器上，绘图脚本回退到系统 CJK 字体；字体不同会使图内文字排布略有差异，但几何与版式检查仍可运行，正文与数值不受影响。

## D 选型决策速查表

### D.1 表示选型

表示选型按第 2 章的结论：表示一旦把性质不同的结构合并，后续模型通常难以恢复这部分误差。判断顺序是先看任务需要保留哪一类信息，再按单位代价换来的误差下降排序。存储与碰撞数字来自表示预算的复算结果。[^repr]

| 任务 | 推荐表示 | 理由 |
| --- | --- | --- |
| 小样本、需可解释 | 物理化学描述符（Mordred 1826 维） | 维度低、每维有物理含义，几百条样本可拟合；分布外结构可能失效 |
| 拓扑敏感（支化、序列、连接方式） | 原子图或重复单元图 | 保留连接关系，消息传递在图上定义；计算与存储代价最高 |
| 超大规模筛选（百万级候选） | 位指纹（ECFP4，Morgan 半径 2、2048 位） | 256 B/分子、百万级 256 MB，全库两两比较可行；2048 位碰撞概率低于 $10^{-600}$ |
| 需要三维信息（构象、几何） | 三维坐标与距离矩阵，或等变网络 | 距离矩阵保留几何；柔性链构象不唯一，等变网络绕开构象枚举 |
| 完整结构且用序列模型 | PSMILES/BigSMILES 字符串 | 保留完整结构，需先规范化；BigSMILES 用参数描述统计结构 |

### D.2 模型选型

模型能力必须与数据规模匹配。学习曲线 $\mathrm{MAE}(n)=0.05+n^{-0.5}$ 给出样本量的量级：$10^{2}$ 条约 0.15，$10^{3}$ 条约 0.08，$10^{4}$ 条约 0.06。目标 MAE 0.2 需约 45 条样本，收紧到 0.1 需 400 条，边际数据 355 条。结论来自第 6、7、9、11 章，数字来自学习曲线反解。[^lc]

| 样本量 | 性质预测 | 生成 | 序贯优化 |
| --- | --- | --- | --- |
| $10^{2}$ | 描述符 + 线性/核/高斯过程；多任务共享表示与物理约束 | 微调预训练生成器，不从零训练 | 高斯过程 + 期望改进（EI） |
| $10^{3}$ | 树集成、高斯过程、带预训练的图网络 | 条件 VAE/GAN，带可合成性约束 | 高斯过程或集成代理 + 采集函数 |
| $10^{4}$ 以上 | 图神经网络或序列 Transformer | 自回归语言模型或扩散，百万级语料预训练 | 稀疏变分高斯过程、集成代理、批量与成本感知采集 |

### D.3 闭环实验设计选型

序贯策略的收益在候选空间大、命中率低时最大。$10^{6}$ 个候选、目标前 0.1% 的任务上，随机采样首次命中的期望是 1000 次实验；贝叶斯优化在声明加速比 5 下降到 200 次；按 50 次/天计，日历时间从 20 天降到 4 天。数字来自闭环采样效率的复算结果。[^cl]

| 搜索空间 | 实验预算 | 推荐策略 | 理由 |
| --- | --- | --- | --- |
| $10^{3}$ 及以下 | 任意 | 穷举或随机采样 | 空间小于预算，序贯收益有限 |
| $10^{4}$–$10^{6}$ | $10^{1}$–$10^{2}$ 次 | 贝叶斯优化（高斯过程 + EI） | 命中率低时几何期望大，序贯可省数倍实验 |
| $10^{6}$ 以上 | $10^{2}$ 次以上 | 批量或成本感知贝叶斯优化、主动学习 | 代理训练 $O(N^{3})$，千级样本以上改用稀疏变分或集成 |

## E 数据与实验的风险清单

**文献物性数据本身可能有误。** 清洗只处理缺失字段、单位不统一与格式不一致，难以剔除文献中已经测错的数值。清洗后的数据集仍带着原始测量的误差与缺失的测量条件，模型在这些标签上学到的规律，其精度上限主要由标签本身的错误率限制。

**未归档来源只用于领域定位。** 正文对未归档来源只说明某个方向存在，不引用其具体数字。所有具体数字来自 `calculations/` 的复算结果或 `references/` 中已归档的来源，未归档与待补的条目记录在 [`references/NEEDED.md`](../references/NEEDED.md)。

**模型预测不替代实验。** 任何 AI 给出的候选，无论预测分数多高，最终必须经湿实验验证。预测影响的是实验的先后顺序与预算分配，不是材料的真实性质；没有实测，候选的性质在数据上仍然未知。

**可合成性的极低比例是理论结果。** $5.7\times10^{-69}$ 这类比例来自组合计数在规则约束下的计算，衡量理论序列空间的可达覆盖，不是实验可及范围。实验可及范围主要由合成路线、单体可得性与收率决定，通常比理论可达空间小得多。[^chemspace]
