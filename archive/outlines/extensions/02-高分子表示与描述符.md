<h2 id="detail-2.1">2.1 为什么表示决定上限</h2>

<h3 id="detail-2.1.1">2.1.1 表示–模型–性能的依赖链</h3>

设表示映射 $g$ 把两个性质不同的结构 $x_1,x_2$ 映射到同一输入 $z=g(x_1)=g(x_2)$，性质差 $\Delta=|y_1-y_2|$。对任一预测器 $f$，两个样本的绝对误差满足

$$\max\big(|f(z)-y_1|,\,|f(z)-y_2|\big)\ \ge\ \frac{\Delta}{2}.$$

因此在被合并的样本对上，任何模型都无法把平均绝对误差压到 $\Delta/2$ 以下。整体不可约误差为

$$\mathrm{MAE}_\text{irr}\ \ge\ \tfrac{1}{2}\,\mathbb{E}\big[\,|y_1-y_2|\ \big|\ g(x_1)=g(x_2)\,\big]\,\Pr[g(x_1)=g(x_2)],$$

它由表示的信息损失与数据噪声共同决定。模型容量只在表示允许的范围内降低误差。

碰撞对内性质差的期望绝对差：若性质差服从方差 $\sigma_c^{2}$ 的分布，$\mathbb{E}\lvert y_1-y_2\rvert=\sigma_c\sqrt{2/\pi}$，因此不可约误差与 $\sigma_c$ 同阶。

<h3 id="detail-2.1.2">2.1.2 从小分子表示到高分子表示</h3>

小分子结构空间由原子种类与连接决定；高分子在其上增加三个自由度：聚合度 $n$、序列排列 $\sigma$ 与分子量分布 $P(M)$。同一组成的样本在 $n$ 或 $\sigma$ 上不同时性质不同，因此表示若不携带 $n$ 或 $P(M)$，标签不可复现。序列信息量随链长线性增长：$N$ 种单体、链长 $L$ 的无规序列有 $N^{L}$ 种，编码需要 $L\log_2 N$ 位。

<h2 id="detail-2.2">2.2 字符串与序列表示</h2>

<h3 id="detail-2.2.1">2.2.1 SMILES 与 PSMILES</h3>

`*` 是 attachment point / dummy atom 约定，标记该位置与相邻重复单元相连。线性重复单元通常用两个连接位；支化与网络架构往往需要多个连接位，或需要更高层的 architecture information，一条 PSMILES 单独不能完整表达真实网络的拓扑、交联点分布与缺陷。三种例子：

- 聚乙烯：`[*]CC[*]`，重复单元含 2 个碳。
- 聚苯乙烯：`[*]CC(c1ccccc1)[*]`，重复单元含 8 个碳与 1 个苯环。
- 聚酰亚胺（示意）：`[*]N(C(=O)c1ccccc1)C(=O)c1ccccc1[*]`，重复单元含 2 个羰基与 2 个芳环。

规范化用 RDKit 的 `MolFromSmiles` 与 `MolToSmiles`：解析成分子图后重新生成唯一字符串。同一结构的不同遍历写法经规范化后得到相同字符串，这是去重与划分的前提。

<h3 id="detail-2.2.2">2.2.2 BigSMILES 与随机结构</h3>

BigSMILES 用花括号 `{ }` 表示随机结构，方括号 `[ ]` 表示确定序列。随机共聚物的组成由各单元在花括号内的排列决定，一个 BigSMILES 字符串对应一个结构分布而非单个分子。设两种单体比例 $p:1-p$、链长 $L$，在**独立 Bernoulli 掺入的教学模型**下，含 $k$ 个 A 单元的概率为

$$\Pr(k)=\binom{L}{k}p^{k}(1-p)^{L-k},$$

序列熵为 $L\,H(p)$（以 nat 计），其中 $H(p)=-p\ln p-(1-p)\ln(1-p)$。要强调该分布不是 BigSMILES 语法自动假设的统计规律：真实 random copolymer 的序列由 reactivity ratio、转化率与加料方式决定，通常不满足独立同分布，第 12 章给出从 $r_1,r_2$ 到序列统计再到性质的链条。PSMILES 只写确定重复单元，BigSMILES 写这个分布。

取 $L=100$、$p=0.5$：$L\,H(0.5)=100\ln 2=69.3$ nat `[复算]`，约 100 位二进制。

<h3 id="detail-2.2.3">2.2.3 序列与共聚组成</h3>

常见序列类型的计数（$N$ 种单体、链长 $L$）：

| 序列类型 | 计数 |
| --- | --- |
| 均聚物 | $N$ |
| 无规 | $N^{L}$ |
| 交替 | $N(N-1)$ |
| 嵌段（两段） | $N(N-1)(L-1)$ |

取 $N=10$、$L=100$，无规序列数 $10^{100}$，比均聚物多 99 个数量级。表示必须区分序列类型，否则同一组成的无规、交替与嵌段样本被当作同一点。

公开库覆盖：$N=10$、$L=100$ 时，PI1M（$10^{6}$）对两段嵌段空间（8910）的覆盖为 $10^{6}/8910=112.2$；对无规空间（$10^{100}$）的覆盖为 $10^{-94}$。

<h2 id="detail-2.3">2.3 指纹与描述符</h2>

<h3 id="detail-2.3.1">2.3.1 拓扑指纹与 ECFP</h3>

ECFP 的原子标识按半径迭代：$r=0$ 时用原子本身属性哈希，$r\ge 1$ 时

$$h_i^{(r)}=\mathrm{hash}\Big(h_i^{(r-1)},\ \{\,h_j^{(r-1)}:j\in\mathcal{N}(i)\,\}\Big),$$

把所有半径 $0\ldots R$ 得到的标识映射到 $n$ 位向量的若干位。ECFP4 取 $R=2$、$n=2048$，等价于 Morgan 半径 2、2048 位。

碰撞要分两层：**语义合并**（序列、MWD、拓扑、加工未编码，位宽无关）与**位碰撞**（折叠后不同子结构落到同一位，位宽相关）。只有第二层可以用位宽讨论。

位碰撞的理想化模型是均匀生日模型：假设 $M$ 个分子在 $2^{n}$ 个位上均匀独立落点，期望碰撞对数

$$\mathbb{E}[\text{collisions}]=\frac{\binom{M}{2}}{2^{n}},\qquad P_c=1-\exp\!\Big(-\frac{\binom{M}{2}}{2^{n}}\Big).$$

取 $M=10^{6}$，$\binom{M}{2}=4.999995\times10^{11}$：

| 位数 $n$ | $2^{n}$ | 理想 $P_c$ |
| --- | --- | --- |
| 32 | $4.29\times10^{9}$ | $\approx 1$ |
| 40 | $1.10\times10^{12}$ | 0.365 |
| 44 | $1.76\times10^{13}$ | 0.0280 |
| 48 | $2.81\times10^{14}$ | $1.77\times10^{-3}$ |
| 64 | $1.84\times10^{19}$ | $2.71\times10^{-8}$ |
| 2048 | $3.23\times10^{616}$ | $1.55\times10^{-605}$ |

真实 ECFP 的置位 bit 数分布有偏、位不独立，与“均匀独立”假设不符，因此上表的 $P_c$ 不是真实碰撞概率，也推不出“安全位数”。工程上应直接测量置位 bit 数分布、稀疏子结构碰撞与重复单元层面的近重复率。均匀生日模型只保留为量级参照（例如用于说明位宽对随机落点碰撞的量级影响）。

<h3 id="detail-2.3.2">2.3.2 物理化学描述符</h3>

Mordred 提供 1826 个二维描述符，按组成（原子计数、环计数）、拓扑（连通性、路径、邻接矩阵特征值）、几何（从二维坐标推导的形状量）与电子（电负性、极性表面积近似）组织。单分子存储 $1826\times4=7304$ 字节；$10^{6}$ 个分子为

$$1826\times4\times10^{6}=7.304\times10^{9}\ \text{B}\approx 7.3\ \text{GB}.$$

同一规模下 2048 位指纹为 $2048/8\times10^{6}=2.56\times10^{8}\ \text{B}\approx 256\ \text{MB}$，相差 28 倍。

<h3 id="detail-2.3.3">2.3.3 描述符规模与冗余</h3>

对第 $j$ 个描述符，以其余描述符回归的决定系数 $R_j^{2}$ 定义方差膨胀因子

$$\mathrm{VIF}_j=\frac{1}{1-R_j^{2}}.$$

$\mathrm{VIF}_j>10$ 通常视为强共线。把相关系数 $|r_{ij}|>0.95$ 的定义为冗余对，去掉每对中与目标相关性较低的一个，可在损失少量信息的前提下降低维度。主成分分析给出另一视角：累计方差达到 99% 所需的主成分数即有效维度，通常远小于名义维度。

<h2 id="detail-2.4">2.4 图与三维表示</h2>

<h3 id="detail-2.4.1">2.4.1 分子图与重复单元图</h3>

分子图 $G=(V,E)$ 中 $|V|=A$ 个原子、$|E|=B$ 条键。节点特征维 $d_v$、边特征维 $d_e$，展平后的输入维度为 $A d_v+B d_e$。取 $A=100$、$B=105$、$d_v=64$、$d_e=16$：

$$100\times64+105\times16=8080\ \text{维},$$

按每元素 1 字节计，每分子 8.08 kB，$10^{6}$ 个分子约 8.08 GB。邻接关系用稀疏索引存储后显著降低。重复单元图把连接点作为特殊节点或边特征，聚合度作为全局属性附加在读出层。

<h3 id="detail-2.4.2">2.4.2 三维构象与几何特征</h3>

三维构象给出原子坐标 $\{r_i\}$，距离矩阵 $D_{ij}=\|r_i-r_j\|$ 含 $\binom{A}{2}$ 个独立距离；键角与二面角由相邻三元组与四元组计算。几何特征对距离、角度与二面角做截断展开，是学习构象相关性质（介电、输运）的输入。构象搜索代价随可旋转键数指数增长，通常由第 5 章的模拟或构象生成器提供。

<h2 id="detail-2.5">2.5 多模态与统一表示</h2>

<h3 id="detail-2.5.1">2.5.1 表示融合</h3>

早期拼接把各表示向量串接：2048 位指纹（展平为 2048 维）加 1826 维描述符加 256 维图读出，得到

$$2048+1826+256=4130\ \text{维}.$$

中期对齐用交叉注意力让一种表示作为查询、另一种作为键值，输出维度与查询一致，避免维度随模态数线性增长。后期集成对各模型输出加权，权重由验证集误差的倒数归一化得到。融合前必须把各分量标准化，否则量纲大的分量主导距离。

<h3 id="detail-2.5.2">2.5.2 表示选择与评估</h3>

给定任务，用固定划分与固定模型比较表示，把收益归因到表示本身。选择判据写成代价归一化的得分

$$S=\frac{\Delta \text{MAE}}{\Delta \text{cost}},$$

其中 cost 用每分子存储或单次前向时间度量。对样本量小、需解释的任务优先描述符；对拓扑敏感、样本充足的任务优先图表示；对超大库筛选优先位指纹。

<h2 id="detail-2.6">2.6 高分子的四层表示对象</h2>

四层表示对象把表示要承载的信息写成四个坐标。本节给出各层字段定义、编码方式与缺失后果，并给出 MWD 的对数正态模型与架构参数的核算。

<h3 id="detail-2.6.1">2.6.1 化学层：重复单元与立构规整度</h3>

化学层字段：重复单元原子组成与连接（由 PSMILES 给出）、端基、立构规整度。立构规整度按手性中心排列分为全同（isotactic）、间同（syndiotactic）与无规（atactic）。PSMILES 用立体标记 `@`/`@@` 写单个手性中心，整链规整度作为整体参数附加。

端基占比：数均聚合度 $n$ 时，链端数占总重复单元数的比例约为 $2/n$；$n=10$ 时约 20%，$n=1000$ 时约 0.2%。规整度的信息量：$L$ 个手性中心、每个两种取向，逐位点序列数为 $2^{L}$；整链平均把它压成 3 类。$L=100$ 时 $2^{100}\approx1.3\times10^{30}$，逐位点信息丢失是 2.1.1 第一项误差的来源。

<h3 id="detail-2.6.2">2.6.2 序列层：从均聚到梯度</h3>

六种序列类型的计数（$N$ 种单体、链长 $L$）：

| 序列类型 | 计数 |
| --- | --- |
| 均聚物 | $N$ |
| 交替 | $N(N-1)$ |
| 两嵌段 | $N(N-1)(L-1)$ |
| 无规 | $N^{L}$ |
| 梯度 | 由组成沿链的变化函数描述，连续参数 |
| 接枝 | 由主链、支链长度与接枝密度描述 |

取 $N=10$、$L=100$：均聚 $10$、交替 $90$、两嵌段 $10\times9\times99=8910$、无规 $10^{100}$，无规序列编码需 $L\log_2 N=332$ 位。

<h3 id="detail-2.6.3">2.6.3 分子量层：数均、重均与分布</h3>

数均与重均分子量定义为

$$M_n=\frac{\sum_i N_i M_i}{\sum_i N_i},\qquad M_w=\frac{\sum_i N_i M_i^{2}}{\sum_i N_i M_i},\qquad Đ=\frac{M_w}{M_n},$$

其中 $N_i$ 是分子量为 $M_i$ 的链数。对数正态模型设 $\ln M$ 服从均值 $\mu$、方差 $\sigma^{2}$ 的正态分布，则

$$Đ=\exp(\sigma^{2}),\qquad M_n=\exp\!\Big(\mu+\frac{\sigma^{2}}{2}\Big),\qquad M_w=\exp\!\Big(\mu+\frac{3\sigma^{2}}{2}\Big),$$

重量分布为

$$w(M)=\frac{1}{M\sigma\sqrt{2\pi}}\exp\!\Big(-\frac{(\ln M-\mu)^{2}}{2\sigma^{2}}\Big).$$

固定 $M_n=100$ kg/mol：Đ $=1.5$ 对应 $\sigma^{2}=\ln 1.5=0.405$，Đ $=2$ 对应 $\sigma^{2}=\ln 2=0.693$，Đ $=4$ 对应 $\sigma^{2}=\ln 4=1.386$。图 2-6 按此模型绘制。玻璃化转变温度的分子量依赖写成

$$T_g(M_n)=T_{g,\infty}-\frac{K}{M_n},$$

其中 $T_{g,\infty}$ 是无穷分子量极限，$K$ 与端基自由体积有关。

MWD 作为表示的三级分辨率：$M_n$（1 个数）、$M_n$ 与 Đ（2 个数）、$P(M)$（曲线）。按 float32 存，一个数 4 B；曲线取 100 个分箱为 400 B/分子，超过 2048 位指纹的 256 B。

<h3 id="detail-2.6.4">2.6.4 架构层：从线性到网络</h3>

架构参数：支化度 $g'$、臂数 $f$、接枝密度 $\sigma_{\text{graft}}$、交联密度 $\nu$。同分子量下星形（$f$ 臂）与线性的熔体黏度相差可达一个数量级，因为星形的臂不能整链缠结。元数据存储：四个 float32 参数共 16 B/分子，占 256 B 指纹的 6.25%；相对稠密描述符可忽略。

<h2 id="detail-2.8">2.8 代表性工作与里程碑</h2>

<h3 id="detail-2.8.1">2.8.1 从 QSPR 到 Polymer Genome</h3>

Morgan 1965 用拓扑描述子唯一编码结构。Polymer Genome 以重复单元化学描述符为输入、多性质监督回归，PolyBERT 论文报告其在 29 性质上的总体 $R^{2}=0.81$，作为学习式表示的对照基线。

<h3 id="detail-2.8.2">2.8.2 学习式表示：PolyBERT 与 TransPolymer</h3>

PolyBERT：预训练语料 $10^{8}$ 条假设 PSMILES，下游 29 性质，总体 $R^{2}=0.80$（五折交叉验证 + 元学习器），对照 Polymer Genome 指纹 $R^{2}=0.81$。TransPolymer：预训练约 $5\times10^{6}$ 条增强 SMILES，十个下游数据集平均 RMSE 0.61、平均 $R^{2}=0.73$；其对照中图神经网络训练 $R^{2}=0.90$、测试 $R^{2}=0.16$，说明划分不当会让任何表示给出虚高或虚低的结论。

<h2 id="detail-2.9">2.9 Worked example：一批候选结构的表示选择与代价核算</h2>

<h3 id="detail-2.9.1">2.9.1 任务与候选库</h3>

任务：预测 $T_g$ 并筛前 $k$。候选库 $M=10^{6}$（PI1M 量级），重复单元约 100 原子、105 键。

<h3 id="detail-2.9.2">2.9.2 结构到表示的账本</h3>

存储核算见 2.7.2 的账本。全库两两比较次数 $\binom{M}{2}=4.999995\times10^{11}$。指纹 XOR-popcount 字操作：$2048/64=32$ 字/次，$4.999995\times10^{11}\times32=1.5999984\times10^{13}$。描述符全库两两比较维操作：$4.999995\times10^{11}\times1826=9.13\times10^{14}$。

<h3 id="detail-2.9.3">2.9.3 模型输入与代价</h3>

GNN（4 层、隐藏 256、100 原子、105 键、边特征 32、8 头）：单分子前向 $3.27361\times10^{8}$ FLOPs，参数量 1,948,674；全库一次前向 $3.27361\times10^{14}$ FLOPs。Transformer 基线（同层同宽、token=原子数）：单分子 $6.70237\times10^{8}$ FLOPs，全库 $6.70\times10^{14}$ FLOPs，约为 GNN 的 2.05 倍。操作数之比（GNN/指纹 $=20.4$，描述符/指纹 $=57.1$）只说明量级差异，不能换算成时间比：字操作、维操作与模型前向的设备吞吐不同。

<h3 id="detail-2.9.4">2.9.4 结论</h3>

分层筛选：指纹（$10^{6}$）→ 描述符（$10^{4}$）→ GNN（$10^{3}$）。全库 GNN 的 $3.27\times10^{14}$ FLOPs 降到 $1.6\times10^{13}$（指纹全库）加 $3.27\times10^{11}$（$10^{3}$ 次 GNN 前向）。

切换规模依赖实测吞吐：操作数之比（描述符/指纹 $=57.1$，GNN/指纹 $=20.4$）只能说明量级差异，不能推出时间比。要定候选缩到多小才值得上描述符或 GNN，需在目标设备、批量与实现下测 molecules/s 或 wall time/molecule；本书未测，因此只给顺序（指纹、描述符、GNN），不给切换规模。

<h2 id="detail-2.10">2.10 表示方案的定量对比</h2>

存储：指纹 256 MB、描述符 7.3 GB、图 8.08 GB（$10^{6}$）。碰撞：$\binom{M}{2}=4.999995\times10^{11}$，均匀生日模型在 $n=32$ 时 $P_c\approx1$、$n=64$ 时 $2.71\times10^{-8}$、$n=2048$ 时约 $10^{-600}$；该模型假设位均匀独立，与真实 ECFP 不符，只作理想化参照，不给安全阈值。真实碰撞按置位 bit 数分布、稀疏子结构碰撞与重复单元近重复率实测。

<h2 id="detail-2.13">2.13 练习与实验清单</h2>

汇总核心练习 2-1 至 2-3 与延伸实验 2-4 至 2-7。

## 延伸实验

> **实验 2-4 ★〔延伸〕：图特征维度核算**
>
> 给定原子数、键数、节点与边特征维以及层数与隐藏维，核算一张分子图的输入特征维度、每层消息传递的张量规模与每分子存储，并与指纹和描述符对照。参数：$A=100$、$B=105$、$d_v=64$、$d_e=16$、4 层、隐藏 256。
>
> 条件：进阶 · `calculations/gnn-forward` 与 `gnn-forward-4layer` 结果。
>
> **记录结果（2-4）：** 展平输入特征 $100\times64+105\times16=8080$ 维，每分子 8.08 kB，比 2048 位指纹（256 B）高约 32 倍；隐藏层张量随层数线性增长。完整记录见 [实验 2-4](../../../experiments/ch02/02-04/README.md)。

> **实验 2-5 ★〔延伸〕：多模态拼接维度**
>
> 把指纹、描述符、图读出与三维几何四种表示拼接，核算拼接维度、标准化前后的尺度差与存储增量，说明为什么拼接前必须标准化。参数：指纹 2048、描述符 1826、图读出 256、三维 64。
>
> 条件：基础 · 纸笔与 `calculations/descriptor-budget`。
>
> **记录结果（2-5）：** 拼接维度为 4194；未标准化时描述符分量的方差远大于指纹分量，会主导距离度量，标准化后各模态贡献可比。完整记录见 [实验 2-5](../../../experiments/ch02/02-05/README.md)。

> **实验 2-6 ★〔延伸〕：四层表示对象的存储账本**
>
> 在 2048 位指纹（256 B/分子）基础上，核算追加化学、序列、MWD 与架构四层字段的元数据存储开销。参数：$M=10^{6}$；端基与规整度各 1 个 float32；序列类型 1 个枚举；$M_n$ 与 Đ 各 1 个 float32；完整 MWD 曲线取 100 个分箱；架构四个参数各 1 个 float32。
>
> 条件：进阶 · `calculations/descriptor-budget` 与 2.7.2 的账本。
>
> **记录结果（2-6）：** 四个标量层字段共 16 B/分子，占指纹的 6.25%；完整 MWD 曲线 400 B/分子，超过指纹本身的 256 B。结论：标量元数据便宜，分布曲线昂贵；MWD 用 $M_n$ 与 Đ 还是曲线，取决于性质对分布形状的敏感度。

> **实验 2-7 ★〔延伸〕：表示方案的选型评分**
>
> 用 2.9.3 的代价与声明模型，计算指纹、描述符与图三种表示的 $S=\Delta \mathrm{MAE}/\Delta \mathrm{cost}$。代价用存储、理想操作计数与（若可得的）实测 wall time/molecule 三种口径分别代入，说明为什么操作数之比不能直接当时间比，以及为什么切换规模必须由实测吞吐决定。参数：指纹与描述符存储比 28.5、全库操作数比 57.1；MAE 差值取声明值（本书未测，用 1 K 作示意）。
>
> 条件：进阶 · `calculations/gnn-forward-4layer`、`descriptor-morgan-2048` 与 `descriptor-mordred-1826` 结果。
>
> **记录结果（2-7）：** 用操作数之比会得到约 $1.8\times10^{4}$ 的“阈值”，但它建立在“三种操作吞吐相同”的错误假设上；用存储口径得到的结论又不同。结论：分层筛选的顺序（指纹、描述符、图）稳健，但具体切换规模必须由目标设备上的实测 molecules/s 或 wall time/molecule 决定，本书未测。
