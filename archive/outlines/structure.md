# 《AI4Polymer：人工智能驱动的高分子材料设计》结构说明

> 写作大纲的顶层文件 · 2026-09-16

本文件记录全书的主张、章节依赖、每章要回答的问题与验收标准。它是提纲系统的入口：`chapters.json` 是机器可读目录，`NN-*.md` 是逐章大纲，`extensions/NN-*.md` 是扩写资料。

## 全书主张

高分子材料的设计长期依赖经验试错：一次合成—表征—迭代周期以天到月计，可用样本以百到千计，而候选化学空间以 $10^{60}$ 量级计。人工智能改变的不是某一步的速度，而是**在有限实验预算下搜索这个空间的策略**。

本书的主张是：**用表示、数据、模型与闭环四个环节，把高分子的设计问题转写成一个可以在有限预算内求解的搜索问题，并从约束推导每一步的设计选择。** 判断一个方法是否值得投入，标准是它在给定预算下把可行解的比例提高了多少，而不是它在某个榜单上高了多少。

由此推出贯穿全书的五个问题，它们对应设计链条上的五个环节：

- **表示什么**：把链结构、序列与构象写成模型可读的输入。
- **数据够不够**：样本量、标签质量与划分方式决定结论能外推多远。
- **用什么模型**：从树集成到图神经网络再到基础模型，模型能力与数据规模必须匹配。
- **怎么搜索**：生成、逆向设计、贝叶斯优化与主动学习在预算下如何分配。
- **闭环到什么程度**：从离线预测到自驱动实验室，每提高一级自动化需要付出什么代价。

## 阅读对象与前置

读者是材料、化学、化工与计算机方向的高年级本科生、研究生与研发工程师，希望把数据驱动方法用在高分子设计与研发上。前置知识为大学化学（高分子基础）、微积分与线性代数、Python 编程。书中每个数量级估算都给出公式与复算脚本，读者不需要 GPU 集群即可跟算。

## 每章的交付

每章必须包含以下内容，缺一不可：

1. **本章判断**：本章的核心论断，一句话。
2. **前置与交付**：需要的数学/化学/编程前置，以及读完能做什么。
3. **正文小节**：`N.M` 与 `N.M.K` 连续编号，每个小节在 `extensions/NN-*.md` 中有对应锚点。
4. **配图**：2–3 张，`> **图 N-Y：…（已配正文图）**`，说明结论与读法。
5. **实验**：恰好 3 个 `〔核心〕` 实验，另有若干 `〔延伸〕`；编号 `N-1` 起连续；每个实验给出条件、记录方式与结果落点。
6. **本章的设计决定**：列出本章涉及的、影响后续章节的取舍。
7. **写作资料**：可追溯到 `references/sources.tsv` 的文献与仓库内文件。

## 验收标准

- `python3 scripts/render_outline.py` 通过，`archive/outlines/README.md` 的章节索引与统计由脚本生成。
- `python3 scripts/verify_outline.py` 报告 `status: passed`。
- 每章实验编号连续、恰好 3 个核心、每个实验都有分类。
- 每章每个小节在扩写资料中都有 `id="detail-N.M"` 锚点。
- 正文中的每个数字都能追溯到 `calculations/` 的结果或 `references/` 中归档的来源。
- 正文不出现参考/证据小节，来源一律用脚注；`## 本章小结` 是最后一节。

## 与 AI Infra 体例的对应

本书沿用《深入理解 AI Infra》的工程体例：单一 Markdown 正文来源、提纲与正文分离、可复现计算工具、归档式引用、PDF 与网站自动构建。差别在于：AI Infra 的主张是"从约束推导设计"，本书把约束换成**实验预算**；AI Infra 的五问是数据搬运，本书的五问是设计链条。
