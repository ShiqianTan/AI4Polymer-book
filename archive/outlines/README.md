## 章节索引

1. [初识 AI4Polymer](01-%E5%88%9D%E8%AF%86%20AI4Polymer.md): 从高分子研发的传统路径与瓶颈出发，给出表示、数据、模型、优化与实验闭环五层全景，用文献规模、化学空间与迭代代价三组数字说明 AI 能改变什么，交代全书估算方法与路线图，并展开高分子与小分子的信息差异、领域简史、设计流水线、五类典型任务与三个贯穿全书的案例。
2. [高分子表示与描述符](02-%E9%AB%98%E5%88%86%E5%AD%90%E8%A1%A8%E7%A4%BA%E4%B8%8E%E6%8F%8F%E8%BF%B0%E7%AC%A6.md): 把高分子变成模型能读的输入：从 SMILES、PSMILES、BigSMILES 等字符串表示，到 ECFP 指纹与物理化学描述符，再到分子图、三维构象与多模态融合，核算每种表示的维度、存储与信息损失。
3. [数据、基准与可复现性](03-%E6%95%B0%E6%8D%AE%E3%80%81%E5%9F%BA%E5%87%86%E4%B8%8E%E5%8F%AF%E5%A4%8D%E7%8E%B0%E6%80%A7.md): 讨论数据从实验、模拟与文献中如何汇聚为 PoLyInfo、PI1M、Open Macromolecular Genome 等数据集，分析小样本、标签噪声、单位缺失与数据泄漏，并建立划分、报告与基准规范。
4. [高分子物理与结构–性能关系](04-%E9%AB%98%E5%88%86%E5%AD%90%E7%89%A9%E7%90%86%E4%B8%8E%E7%BB%93%E6%9E%84%E6%80%A7%E8%83%BD%E5%85%B3%E7%B3%BB.md): 梳理分子量与链构象、玻璃化转变与结晶、力学与流变、介电与输运等结构–性能关系，判断哪些性质容易被数据驱动方法学到，哪些必须引入机理约束。
5. [分子模拟与多尺度计算](05-%E5%88%86%E5%AD%90%E6%A8%A1%E6%8B%9F%E4%B8%8E%E5%A4%9A%E5%B0%BA%E5%BA%A6%E8%AE%A1%E7%AE%97.md): 从量子化学、分子动力学到粗粒化与机器学习力场，建立方法–尺度–精度的对应关系，核算 DFT、MD 与机器学习势的计算代价，并说明模拟如何为模型生成标签。
6. [性质预测模型](06-%E6%80%A7%E8%B4%A8%E9%A2%84%E6%B5%8B%E6%A8%A1%E5%9E%8B.md): 从线性与核方法、树集成、高斯过程到图神经网络与序列 Transformer，给出性质预测的统一问题设定、评价指标与模型选择方法，并核算前向与训练代价。
7. [多任务、迁移与物理信息学习](07-%E5%A4%9A%E4%BB%BB%E5%8A%A1%E8%BF%81%E7%A7%BB%E4%B8%8E%E7%89%A9%E7%90%86%E4%BF%A1%E6%81%AF%E5%AD%A6%E4%B9%A0.md): 针对高分子数据稀缺与性质相关的特点，讨论多任务共享表示、预训练–微调与少样本迁移、自监督预训练，以及物理信息神经网络、等变网络与守恒约束，并给出外推、负迁移与失败模式的评估方法。
8. [表征、成像与光谱的 AI 分析](08-%E8%A1%A8%E5%BE%81%E6%88%90%E5%83%8F%E4%B8%8E%E5%85%89%E8%B0%B1%E7%9A%84%20AI%20%E5%88%86%E6%9E%90.md): 面向图像、光谱与散射衍射数据，讨论分割与检测、谱–结构映射、从表征反推结构以及多表征融合，并核算分析吞吐与主动测量的收益。
9. [生成模型与高分子序列设计](09-%E7%94%9F%E6%88%90%E6%A8%A1%E5%9E%8B%E4%B8%8E%E9%AB%98%E5%88%86%E5%AD%90%E5%BA%8F%E5%88%97%E8%AE%BE%E8%AE%A1.md): 从 VAE、GAN 到扩散、流匹配、掩码生成与自回归语言模型，用统一模板逐族比较目标、采样、优缺点与聚合物适配；给出高分子特有的七项生成挑战、评价指标与陷阱，以及性质、组成、序列条件生成的实现与失败模式。
10. [逆向设计与多目标材料设计](10-%E9%80%86%E5%90%91%E8%AE%BE%E8%AE%A1%E4%B8%8E%E5%A4%9A%E7%9B%AE%E6%A0%87%E6%9D%90%E6%96%99%E8%AE%BE%E8%AE%A1.md): 把性质预测反转为设计问题，讨论优化式与生成式逆向设计、Pareto 前沿与多目标权衡，并建立从海量候选到可验证材料的筛选漏斗。
11. [主动学习、贝叶斯优化与强化学习](11-%E4%B8%BB%E5%8A%A8%E5%AD%A6%E4%B9%A0%E8%B4%9D%E5%8F%B6%E6%96%AF%E4%BC%98%E5%8C%96%E4%B8%8E%E5%BC%BA%E5%8C%96%E5%AD%A6%E4%B9%A0.md): 把材料设计看作序贯决策：用高斯过程代理与采集函数实现贝叶斯优化，用不确定性采样实现主动学习，用强化学习处理序列设计，并核算采样预算与收敛。
12. [反应预测、聚合建模与可合成性](12-%E5%8F%8D%E5%BA%94%E9%A2%84%E6%B5%8B%E8%81%9A%E5%90%88%E5%BB%BA%E6%A8%A1%E4%B8%8E%E5%8F%AF%E5%90%88%E6%88%90%E6%80%A7.md): 面向合成的可行性：讨论反应类型与聚合动力学、竞聚率与共聚序列、分子量分布与反应条件预测、逆合成与路线规划，以及规则法与学习法两种可合成性评分，并核算从 10^100 到 8910 的路线长度与可合成性。
13. [自驱动实验室与高通量自动化](13-%E8%87%AA%E9%A9%B1%E5%8A%A8%E5%AE%9E%E9%AA%8C%E5%AE%A4%E4%B8%8E%E9%AB%98%E9%80%9A%E9%87%8F%E8%87%AA%E5%8A%A8%E5%8C%96.md): 把模型与机器人实验连成闭环：介绍自驱动实验室组成、液体处理与在线表征平台、高通量实验的并行化与数据管理，拆解软件栈与硬件模块，核算调度、可靠性、实验周期、吞吐与机器人利用率，并用公开案例与闭环核算给出成本与选型判据。
14. [高分子基础模型与智能体系统](14-%E9%AB%98%E5%88%86%E5%AD%90%E5%9F%BA%E7%A1%80%E6%A8%A1%E5%9E%8B%E4%B8%8E%E6%99%BA%E8%83%BD%E4%BD%93%E7%B3%BB%E7%BB%9F.md): 讨论高分子领域的预训练基础模型、文献知识抽取与 RAG、工具调用与多智能体协作，并评估幻觉、事实性与任务成功率，给出与计算和实验工具的集成方式。
15. [可持续高分子与环境应用](15-%E5%8F%AF%E6%8C%81%E7%BB%AD%E9%AB%98%E5%88%86%E5%AD%90%E4%B8%8E%E7%8E%AF%E5%A2%83%E5%BA%94%E7%94%A8.md): 把可持续性写成设计目标与约束：沿生命周期讨论原料、聚合、使用与废弃四个阶段，建立 LCA 目标函数、四条废弃路径的硬约束与 end-of-life 情景，并给出性能–成本–碳足迹–可回收率的多目标核算与应用案例。
16. [端到端案例与工程实践](16-%E7%AB%AF%E5%88%B0%E7%AB%AF%E6%A1%88%E4%BE%8B%E4%B8%8E%E5%B7%A5%E7%A8%8B%E5%AE%9E%E8%B7%B5.md): 用高 Tg 透明聚酰亚胺、可回收热固性材料与气体分离膜三个案例走通从需求、数据、建模、生成到验证的完整流程，并总结数据与模型治理、团队流程与常见失败模式。

## 维护方式

```bash
python3 scripts/render_outline.py    # 同步本文件索引与来源落点
python3 scripts/verify_outline.py    # 校验编号、实验分类、锚点与链接
python3 calculations/calc.py sync-outline   # 把复算结果写回 extensions/
```

改完大纲后先跑 `render_outline.py`，再跑 `verify_outline.py`，`status` 为 `passed` 才算完成。
