# 第 6 章基准：聚酰亚胺玻璃化转变温度的性质预测

本目录是第 6 章 6.10 节 Worked example 的可运行实现。它用第 16 章旗舰案例已下载的真实公开 $T_g$ 数据，在**只依赖 Python 标准库**的前提下跑通一条完整基准：数据清洗 → 表示构造 → 五种划分 → 六个模型 → 多种子评测 → 不确定度 → 学习曲线。所有数字由本目录脚本真实产出，未编造；跑不出来的模型如实标注。

## 快速开始

```bash
cd experiments/ch06/benchmark
python3 run.py
```

运行时间约 10 分钟（纯 Python，无第三方依赖），结果写入 `results/`。固定随机种子 `[42, 7, 13, 2024, 99]`，主种子 `42`；`results/manifest.json` 记录输入与全部输出的 SHA256。

依赖：Python 3.11 标准库（`csv`、`hashlib`、`json`、`math`、`random`、`collections`、`pathlib`）。不需要 numpy、RDKit 或 scikit-learn。

## 表示构造

脚本自带一个最小 SMILES 解析器，把重复单元串解析成原子–键图（支持方括号原子、芳香原子、环闭合数字与 `%nn`、分支、`- = # :` 键级、`.` 断开），再构造两类特征。

**图描述符（21 维，可解释）**：重原子数、各元素计数（C/N/O/F/S/Si/其他）、环原子数、芳香原子数、CF3 数、羰基数、醚氧数、砜基数、酰亚胺氮数、双键数、单键数、芳香原子占比、杂原子占比、环原子占比、连接点数。

**Morgan 类子结构指纹（256 位，计数）**：以原子不变量（元素、芳香性、电荷、度）为初始标识，迭代 2 轮把邻居标识混入自身标识，每轮把标识散列进 256 位。这是标准 ECFP 的纯 Python 实现，与 RDKit 的 Morgan 指纹同源。

组合特征 277 维（21 描述符 + 256 指纹位）。

**分组键（用于划分）**，三档粒度：

- `scaffold`：对图做 Murcko 式剪枝（迭代删除不在环上的度 1 原子），对剩余骨架做 3 轮 Weisfeiler–Lehman 标识并散列。1366 个不同骨架。
- `monomer`：粗粒度单体家族，由整分子元素计数与环数组成。1199 个家族。
- `chemistry`：整分子 2 轮 WL 子结构签名（取字典序前 6 个标识散列）。695 个子结构族，粒度最细。

## 模型

六个模型全部用标准库实现：

| 模型 | 实现 |
| --- | --- |
| 均值基线 | 训练集 $T_g$ 均值 |
| 线性回归 | 正规方程最小二乘（高斯消元，含 $10^{-6}$ 稳定项） |
| Ridge | 闭式解 $(\mathbf X^\top\mathbf X+\lambda I)^{-1}\mathbf X^\top\mathbf y$ |
| SVR | 线性 $\varepsilon$-不敏感 SVR，次梯度下降（$\varepsilon=0.1$，L2 正则 $10^{-3}$，60 轮） |
| 随机森林 | CART 回归树，bootstrap + 特征子采样，30 棵树，最大深度 10，叶最少 5 条 |
| 梯度提升 | 逐棵拟合残差的 CART，深度 3、学习率 0.05、120 棵树（XGBoost 的标准库替代） |

## 主结果（scaffold 分组划分，5 个种子）

单位 K。均值 ± 标准差，跨 5 个种子（训练约 1410 条、测试约 355 条、骨架重叠为 0）。

| 模型 | MAE | RMSE | $R^2$ | Spearman |
| --- | --- | --- | --- | --- |
| 均值基线 | 59.39 ± 2.12 | 76.91 | -0.01 | 0.00 |
| 线性回归 | 32.92 ± 1.19 | 47.00 | 0.62 | 0.80 |
| Ridge（$\lambda=10$） | 31.49 ± 1.39 | 44.49 | 0.66 | 0.81 |
| Ridge（$\lambda=1$） | 32.52 ± 1.40 | 46.25 | 0.63 | 0.80 |
| SVR（线性 $\varepsilon$-不敏感） | 29.83 ± 1.01 | 44.08 | 0.67 | 0.82 |
| 随机森林 | **29.48 ± 1.79** | **40.73** | **0.72** | **0.83** |
| 梯度提升 | 30.56 ± 1.88 | 42.00 | 0.70 | 0.82 |

逐种子 MAE（随机森林）：28.21、30.26、28.80、32.58、27.56。种子间标准差 1.79 K，与「随机森林比梯度提升好 1.08 K」同量级——这个差距不能只报一次种子就下结论。

读法：三层基线（均值 59.39、线性 32.92、Ridge 31.49）把「什么都不学」「只学线性」「学一点非线性」的误差依次压下来；随机森林与 SVR 再各降约 2 K。模型之间的差距在 1–3 K，远小于种子间波动之外的任何「大改进」叙事。

## 划分对比（3 个种子）

| 划分 | Ridge MAE | 梯度提升 MAE | 训练/测试 | 分组数 |
| --- | --- | --- | --- | --- |
| random | 30.91 ± 0.91 | 29.84 ± 1.11 | 1412 / 353 | 1765 |
| scaffold | 32.24 ± 1.70 | 29.71 ± 0.95 | 1410 / 355 | 1366 |
| monomer | 29.99 ± 1.87 | 30.54 ± 1.57 | 1412 / 353 | 1199 |
| chemistry | **38.84 ± 1.82** | **34.48 ± 1.32** | 1402 / 363 | 695 |

结论有三条。第一，随机划分与分组划分对梯度提升几乎无差别（29.84 对 29.71），但对 Ridge 有差别（30.91 对 32.24）：树模型用局部划分记住了同系物，Ridge 用全局线性系数做不到。第二，越细的分组越难：`chemistry` 子结构划分把梯度提升误差从 29.71 推到 34.48 K。第三，`monomer` 粗粒度划分反而比 `scaffold` 容易，因为它把更多结构留在同一组，测试组更可能被训练组覆盖。

`time` 划分**本书未运行**：这份数据集没有发表年份或测量日期字段，无法构造时间划分。这不是遗漏，而是数据限制。

## 表示消融（scaffold 划分，种子 42）

| 特征集 | 维度 | Ridge MAE | 梯度提升 MAE |
| --- | --- | --- | --- |
| 仅描述符 | 21 | 40.29 | 35.22 |
| 仅指纹 | 256 | 31.85 | 30.41 |
| 组合 | 277 | 31.39 | **28.36** |

描述符单独用明显弱于指纹（Ridge 差 8.4 K），两者组合比指纹单独用再降约 2 K（梯度提升 30.41 → 28.36）。这给出第 2 章表示融合的一个真实数据点：两类表示信息互补，但指纹是主力。

## 不确定度（scaffold 划分，种子 42）

**Split conformal**（在训练集内再切 80/20 做拟合与校准，取绝对残差分位数）：

| 名义覆盖 | 实测覆盖 | 平均区间宽度 |
| --- | --- | --- |
| 95% | 94.3% | 154.5 K |
| 90% | 90.9% | 130.6 K |
| 80% | 81.0% | 90.2 K |

覆盖接近名义值，说明在骨架分组下 conformal 仍然校准得不错。

**分位数回归**（两个 pinball-loss 提升模型，5% 与 95% 分位）在同样 90% 目标下实测覆盖 90.7%，但平均宽度 278.5 K，约为 conformal 宽度的 2.1 倍。这就是「均值相同、区间不同」的实例：两种方法给出的点预测可以一样，但区间宽度相差一倍，设计含义是分位数回归直接建模条件分位数、对小样本尾部更保守。

**集成方差**：随机森林 30 棵树的预测标准差均值 33.76 K。它给出的是模型内部离散度，不是校准过的覆盖区间；用它筛「需要实验验证」的候选时，先要检验它与绝对误差的相关性。

## 学习曲线（scaffold 划分，种子 42）

| 训练量 | 测试 MAE (K) |
| --- | --- |
| 50 | 42.36 |
| 100 | 35.08 |
| 200 | 31.97 |
| 400 | 31.55 |
| 800 | 30.18 |
| 1200 | 29.35 |

用幂律 $\mathrm{MAE}(n)=A\,n^{-\alpha}$ 拟合得 $A=58.6$、$\alpha=0.102$、拟合 $R^2=0.856$。指数只有约 0.10，远小于第 3 章示意曲线用的 0.5：从 400 条加到 1200 条，误差只从 31.55 K 降到 29.35 K。这与第 16 章旗舰案例在同一数据上拟合的 $\alpha=0.197$ 方向一致（不同流程与模型），都说明几千条样本区间内数据量的边际收益已经很小。
