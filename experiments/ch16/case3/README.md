# 第 16 章 案例三：气体分离膜的真实数据链路

本目录是第 16 章 16.4 节案例三的补充实现。它用**真实公开测量数据**跑通「清洗 → 时间/分组划分 → 渗透率模型 → 选择性 → Robeson 参照线 → 候选筛选」这条链路，并明确标注哪些环节是真实计算、哪些环节因缺少标注数据无法进行。没有湿实验，每个数字都由本目录脚本真实产出，未编造。

## 快速开始

```bash
cd experiments/ch16/case3
python3 run.py
```

运行时间约 5 秒，结果写入 `results/`。脚本**只依赖 Python 标准库**（3.10+），共享工具在 `../stdlib_ml.py`。固定随机种子 `SEED=42`，`results/manifest.json` 记录输入与输出的 SHA256。

## 链路与真实产出

### 1. 清洗

778 条中只有 221 条同时含 CO$_2$ 与 CH$_4$ 实测；其中 4 条 SMILES 过短被丢弃，保留 217 条。这一条**双气体实测**的要求是后续双目标筛选的前提：只有同时测得两种气体，才能算出选择性。

### 2. 划分

三种划分各跑一遍（预测目标为 $\log_{10}P_{\mathrm{CO_2}}$，单位 dex）：

| 划分 | 训练 / 测试 | 均值 MAE | Ridge MAE | 梯度提升 MAE |
| --- | --- | --- | --- | --- |
| 随机 | 173 / 44 | 1.265 | 0.474 | 0.414 |
| 单体家族分组 | 174 / 43 | 1.095 | 0.558 | 0.491 |
| **时间（≤2000 / >2000）** | 49 / 168 | 1.631 | 2.384 | 1.539 |

时间划分暴露了外推失效：训练集只有 49 条 2000 年以前的记录，测试集 168 条为新体系，梯度提升 MAE 升到 1.539 dex，Ridge 甚至差于均值基线（2.384 对 1.631）。这与第 3 章「时间划分更接近真实部署」的结论一致，也说明小数据下时间外推的代价。

### 3. 模型与不确定度

按单体家族分组 5 折交叉验证：梯度提升 MAE **0.428 ± 0.104 dex**。split conformal 90% 名义覆盖 → 实测 **90.7%**，平均区间宽度 **2.298 dex**。选择性的预测 MAE 为 **0.254 dex**（$\log_{10}\alpha$）。

### 4. Robeson 参照线（本书从数据拟合）

把 217 条实测点按 $\log_{10}\alpha$ 排序，取非支配前沿（不存在另一个点在渗透率与选择性上同时更高），再对前沿点做线性拟合，得到

$$\log_{10}P_{\mathrm{CO_2}}=5.486-1.310\,\log_{10}\alpha .$$

这条线由本数据集拟合，**不是 Robeson 2008 的发表值**；报告 $d$ 时必须说明上限参数来源。位置量 $d=\log_{10}P-(\log_{10}\beta-n\log_{10}\alpha)$，$d>0$ 表示在上限之上。

### 5. 候选筛选漏斗

对 1124 个无标签结构预测 $\log_{10}P_{\mathrm{CO_2}}$ 与 $\log_{10}P_{\mathrm{CH_4}}$，取比值得到选择性：

| 阶段 | 存活数 |
| --- | --- |
| 候选库 | 1124 |
| 预测 $P_{\mathrm{CO_2}}>100$ Barrer | 65 |
| 同时 $\alpha_{\mathrm{CO_2/CH_4}}>25$ | **0** |
| 且 $d>0$（上限之上） | **0** |

真实结果是**零命中**：模型预测的最大选择性 47.9，232 个结构选择性高于 20，但**没有一个结构同时满足 $P>100$ 与 $\alpha>25$**。这正是渗透率—选择性权衡在数据上的体现，也是小数据 + 高选择性样本稀缺（217 条中仅 30 条 $\alpha>25$）导致模型向均值回归的结果。这与原论文的观察一致：上限之上的标注样本极少，模型很难外推到该区域。

### 7. 验证

- **样本内验证**：分组划分测试集上 $\log_{10}P$ 的 MAE 与选择性 MAE 如上。
- **外部对照**：原论文合成并实验验证了两个超过多组上限的聚酰亚胺；本书未复现其合成与测试，只引用其结论。
- **湿实验与混合气体**：本案例未做合成与渗透测量；数据集只有单气体标签，混合气体选择性与高压条件**无标注数据**，无法建模。

## 哪些环节是真实计算，哪些无法进行

| 环节 | 状态 | 说明 |
| --- | --- | --- |
| 数据与 CO$_2$/CH$_4$ 标签 | 真实 | 公开测量汇编，含年份与条件 |
| 清洗与划分 | 真实 | 双气体要求、解析检查、时间与分组划分 |
| 模型与不确定度 | 真实 | 纯标准库 Ridge / 随机森林 / 梯度提升 + conformal |
| Robeson 参照线 | 真实拟合 | 由本数据集非支配前沿拟合，非 2008 原值 |
| 候选筛选 | 真实 | 1124 个无标签结构，零命中 |
| **混合气体选择性** | **无标注数据** | 只有单气体标签 |
| **高压条件** | **无标注数据** | 压力不是特征 |
| 湿实验 | 未做 | 本案例不含合成与渗透测量 |
