# 第 16 章 案例二：可回收热固性材料的真实数据链路

本目录是第 16 章 16.3 节案例二的补充实现。它用**真实公开数据**跑通「枚举 → 描述符 → 约束筛选 → 候选排序」这条链路，并明确标注哪些环节是真实计算、哪些环节因缺少标注数据无法进行。没有湿实验，每个数字都由本目录脚本真实产出，未编造。

## 快速开始

```bash
cd experiments/ch16/case2
python3 run.py
```

运行时间约 1 分钟，结果写入 `results/`。脚本**只依赖 Python 标准库**（3.10+），不需要 numpy、RDKit 或 scikit-learn；共享的纯标准库化学/机器学习工具在 `../stdlib_ml.py`。固定随机种子 `SEED=42`，`results/manifest.json` 记录输入与输出的 SHA256。

## 链路与真实产出

### 1. 清洗

8424 条全部保留，0 条丢弃：每条都含可解析的酸与环氧 SMILES，且 $T_g$ 落在 [200, 700] K。清洗只做单位统一（数据本身为 K）、范围检查与 SMILES 解析。

### 2. 划分

两种划分各跑一遍：

- **随机划分**：训练 6739、测试 1685；
- **环氧家族分组划分**：按环氧单体的元素计数与环数构成家族键做分组，训练 6732、测试 1692，测试家族的环氧在训练集中不出现，避免同系物泄漏。

### 3. 模型（单位 K）

| 模型 | 随机划分 MAE | 分组划分 MAE |
| --- | --- | --- |
| 全局均值基线 | 26.40 | 26.06 |
| Ridge（$\lambda=10$） | 16.49 | **16.25** |
| 随机森林 | — | 17.47 |
| 梯度提升（主模型） | — | 17.43 |

按环氧家族分组 5 折交叉验证：梯度提升 MAE **17.95 ± 0.49 K**。在这 48 维可解释描述符上，线性 Ridge 与树集成相当，说明描述符与 $T_g$ 的关系在该数据范围内接近线性——与第 6 章基准「模型间差距在 1–3 K」的结论一致。

### 4. 不确定度

split conformal 90% 名义覆盖 → 测试集实测覆盖 **91.2%**，平均区间宽度 **75.3 K**。

### 5. 候选枚举与筛选漏斗

取出现频次最高的 60 个酸与 60 个环氧，枚举 3600 个酸×环氧组合，其中 3599 个不在原数据集中（真实新组合）。筛选漏斗：

| 阶段 | 存活数 |
| --- | --- |
| 枚举（新组合） | 3599 |
| 构建成功（可解析） | 3599 |
| 含动态键前体（环氧乙烷 + 羧基） | 3599 |
| 可交联网络（官能度 ≥ 2） | 3599 |
| 预测 $T_g$ 落入 [350, 420] K 窗口 | 725 |
| 动态键密度 ≥ 0.08 | 71 |

前两级过滤全部通过是真实结果：来源单体本身都是双环氧或双酸，天然满足网络化条件；真正的选择性来自 $T_g$ 窗口与动态键密度。

### 7. 验证

- **外部实验对照**：295 条聚合物的 MD $T_g$ 与实验 $T_g$ 对照，MAE **70.6 K**，系统偏差 **+63.8 K**（MD 高估）。这是标签来源的真实误差，说明校准后的 $T_g$ 仍有数十 K 的不确定度。
- **与原论文交叉核对**：对原论文贝叶斯优化搜索到的 62 个候选，本模型预测 $T_g$ 与其报告值 MAE **20.9 K**。
- **湿实验**：本案例未做合成与表征。原论文合成并表征了一个 vitrimer 并测量了 $T_g$，本书未复现。
- **未建模的量**：解聚温度、模量、回收率在源数据中没有标签，**无法训练**，因此不给出数值，只以动态键密度与 $T_g$ 窗口作为结构代理。

## 哪些环节是真实计算，哪些无法进行

| 环节 | 状态 | 说明 |
| --- | --- | --- |
| 数据与 $T_g$ 标签 | 真实 | 公开 vitrimer 数据，MD 计算 + GP 校准 |
| 清洗与划分 | 真实 | 解析、范围检查、环氧家族分组 |
| 模型与不确定度 | 真实 | 纯标准库 Ridge / 随机森林 / 梯度提升 + conformal |
| 候选枚举 | 真实 | 60×60 单体组合，3599 个新组合 |
| 动态键 / 网络 / $T_g$ 窗口筛选 | 真实计算 + 声明代理 | 动态键密度是结构代理，不是实测 |
| **解聚温度** | **无标注数据** | 源数据没有该标签，无法训练或验证 |
| **模量** | **无标注数据** | 同上 |
| **回收率** | **无标注数据** | 同上 |
| 湿实验 | 未做 | 本案例不含合成与表征 |
